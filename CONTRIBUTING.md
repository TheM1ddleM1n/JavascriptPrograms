# Contributing to JavascriptPrograms

Thank you for your interest in contributing. Every contribution helps make this repository a better resource for people learning JavaScript.

---

## What Can I Add?

Any self-contained JavaScript program is welcome. Some ideas:

- Sorting, searching, graph traversal, or dynamic programming
- Helper functions, string/array utilities, or date formatters
- CLI or browser-based mini games
- Interactive HTML/CSS/JS pages

If you are unsure whether an idea fits, open an issue first to discuss it.

---

## Guidelines

- **One program per file** — keep each file focused and easy to read
- **No external dependencies** — plain JavaScript only (Node built-ins are fine for CLI scripts)
- **Readable code** — use clear, descriptive variable and function names
- **Self-contained** — the file should run on its own via `node yourFile.js`, or in a browser via the developer console (F12)

---

## How to Contribute

1. Fork the repository
2. Create a branch for your program:
```bash
   git checkout -b add-caesar-cipher
```
3. Add your file to the appropriate directory
4. Commit with a clear message:
```bash
   git commit -m "Add caesar cipher utility"
```
5. Open a pull request with a brief description of what your program does

---

## Pull Request Checklist

Before submitting, confirm that:

- [ ] The file runs without errors
- [ ] No external npm packages are used
- [ ] The README table has been updated
- [ ] The file name follows camelCase (e.g. `caesarCipher.js`), lowercase, or UPPERCASE (e.g. `Hangman.js`)
