## Overview

JavascriptPrograms is a curated set of self-contained JavaScript programs, organized by category. Each file is intended to run independently, with no build step and no external dependencies.

## Why This Repo

- **Beginner friendly** — every file is self-contained and easy to follow
- **Wide coverage** — algorithms, data structures, utilities, games, and browser-based projects
- **Zero dependencies** — plain JavaScript only, using Node built-ins where needed
- **Community driven** — open to contributions from anyone

## Repository Structure

| Directory | Description |
|---|---|
| `Algorithms/` | Sorting, searching, graph traversal, and data structure implementations |
| `DOM/` | Browser-based projects using HTML, CSS, and vanilla JavaScript |
| `MiniGames/` | Small CLI and browser games |
| `Quirks/` | Notes and runnable examples on JavaScript's lesser-known behaviors |
| `Utility/` | General-purpose helper functions |

## Getting Started

### Prerequisites

[Node.js](https://nodejs.org) is required to run the CLI scripts. Browser projects require no setup.

### Running a Node.js script

```bash
node Algorithms/bubbleSort.js
```

### Running a browser project

Open the relevant `.html` file directly in a browser. No server is required.
